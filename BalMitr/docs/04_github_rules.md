# GitHub Rules
- `main` = final working branch (merged from `develop` via pull request only).
- `develop` = integration branch; every feature uses a short-lived branch (`feature/<area>-<task>`).
- Keep folders clean: `backend/` (Django API), `ml/` (WHO calculator, risk rules, food rules), `frontend/` (React web app), `docs/` (documentation).
- Never commit secrets, real passwords, API keys, or real children's data.
